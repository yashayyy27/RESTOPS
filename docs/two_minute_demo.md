## Shot preparation

- Keep the reporting period/synthetic label visible; use actual live screens.
- Record the whole browser and narrate readable rounded numbers; pause at controls.
- Scroll to the bridge, simulator result and frozen evidence rather than showing
  a long form at speed. Pre-open the seeded proposal if the recording must stay
  strictly under two minutes; disclose that it is seeded.
- Use on-screen status **proposed**. Do not show an invented approved/achieved
  story. If demonstrating completion, label it a simulated workflow exercise.
- End on README evidence links. Add no unverified Tableau/live-hosting footage.
